# 系统设置移植 - 群聊视觉上下文与多模态转述 (astrbot_plugin_sys_setting_port)

这是一个为 AstrBot 提供群聊上下文感知、图片转述、自定义艾特等待和私聊主动回复的插件。

## 🌟 核心功能

AstrBot 的图片处理和群聊上下文感知分别由不同链路负责。本插件提供按模型、按群聊白名单控制的图片处理，并把群友未直接唤醒 Bot 时的聊天内容作为不保存的临时内容注入当前请求。

本插件提供以下高级特性：

1. **完整群聊上下文**：所有通过 AstrBot 系统白名单的群聊都会按原始消息顺序记录普通文字、At、引用和图片占位；插件图片白名单群的图片会在原位置替换为描述。
2. **“阅后即焚”注入**：最近的群聊感知条目以独立临时上下文消息注入，并通过 `_no_save` 标记阻止 AstrBot 写入会话历史；无法构建临时消息的旧版 AstrBot 才回退到 `system_prompt`。注入内容只参与当前请求。
3. **智能转述判定官**：引入可选的判定模型（如 Gemini Flash 或 GPT-4o-mini），精准识别转述模型返回的“变相拒绝”或“虚假描述”。若判定不通过，将自动触发重试。
4. **硬核报错重试**：自动捕获 403、429、超时等所有底层 API 异常并触发重试，不再依赖脆弱的关键词匹配。
5. **结构化转述提取**：强制转述模型使用 `<caption_result>` 标签，实现描述内容的精准提取，有效隔离模型废话。
6. **多模态直通与插件兼容**：引用图片默认只发送已有描述；当前消息命中“仔细看”“看原图”等关键词时，多模态模型只接收原图与来源。图生图等插件仍可获取引用原图。纯文本模型匹配会综合请求模型名、Provider 实际模型名、配置模型名和 Provider ID。
7. **私聊转述持久化**：私聊中的图片转述结果作为普通用户消息内容保存到会话历史；群聊转述仍只参与当前请求。用于生成描述的转述提示词本身不会写入主会话。
8. **私聊主动回复 (AGI 进化版)**：当私聊闲置时，机器人会主动找用户聊天。支持“纯随机”与“智能判定”双模式，具备硬盘级持久化状态。
9. **自定义等待机制 (增强版)**：接管系统原有的「只 @ 机器人」等待逻辑，支持自定义等待时间、回复词及完美超时唤醒（正确引用原消息）。

## ⚙️ 配置说明

请在 AstrBot 的 WebUI 后台 -> 插件管理 -> `astrbot_plugin_sys_setting_port` 中进行配置：

### 👥 群聊视觉上下文配置
- **启用插件群聊上下文**：启用后由本插件完整替代 AstrBot 原生群聊上下文感知。
- **群聊图片理解白名单**：仅列表中的群号会调用视觉模型生成描述。
- **群聊图片理解模型**：群友发图时使用的视觉模型。

### 🖼️ 多模态转述配置
- **多模态转述模型**：选择用于看图的主力模型。
- **启用智能转述判定**：开启后调用判定模型审核转述质量。
- **转述判定模型 / 提示词**：用于执行判定的轻量级模型及指令。
- **启用结构化转述输出**：强制要求模型使用标签包裹描述内容。
- **需要转述的模型列表**：填入需要被转述的纯文本模型名称（支持模糊匹配）。

## 📝 更新日志

### v2.1.3
- **修复**：将图片转述与群聊上下文拆分为两个 LLM hook；图片转述恢复旧版默认优先级，群聊时间线继续以最低优先级最终注入。
- **修复**：目标模型匹配同时检查 `req.model`、Provider 实际模型名、Provider 配置模型名和 Provider ID，并规范化关键词空格与大小写。
- **持久化**：私聊图片转述结果恢复为普通 `extra_user_content_parts`，随本轮用户消息永久保存；群聊图片转述保持临时。
- **日志**：新增 `【图片转述｜触发】`、`【图片转述｜成功】`、`【图片转述｜主模型失败】`、`【图片转述｜失败】` 醒目标记，显示匹配关键词、当前模型候选、转述 Provider、图片数和注入模式。

### v2.1.2
- **修复**：将 LLM 请求钩子调整为最低优先级，在持久历史等插件完成 `req.contexts` 重建后再执行最终注入。
- **根因**：此前本插件以最高优先级先注入，随后 `astrbot_plugin_persistent_history` 会清空并整体替换 contexts，导致群聊时间线在最终请求前丢失。
- **诊断**：成功日志增加临时上下文在最终 contexts 中的位置；应看到 `群聊上下文已最终注入` 且 `position` 不为 `-1`。

### v2.1.1
- **修复**：群聊上下文改用独立临时上下文消息注入，解决部分版本或 Provider 不读取动态 `system_prompt` 的问题。
- **兼容**：无法构建临时消息的旧版 AstrBot 自动回退到 `system_prompt`。
- **可观测性**：注入成功时记录群号、注入模式、消息条数与字符数，便于从日志直接核验。
- **防膨胀**：临时消息使用 `_no_save` 标记，不写入会话历史；增加重复注入保护。

### v2.1.0
- **重构**：将群聊上下文注入点迁移至 `system_prompt`，尝试实现不写入历史的临时注入。
- **新增**：智能转述判定官功能，精准识别并重试 AI 的拒绝或道歉回复。
- **新增**：结构化转述提取逻辑，支持通过标签精准隔离描述内容。
- **优化**：参考 `nova_omni` 逻辑，通过捕获底层 Exception 实现稳健重试。
- **修复**：修正了群聊视觉感知中的参数传递错误。

### v2.0.0
- **新增**：增加完整群聊上下文，图片描述按原位写入感知记录。
- **新增**：描述复用缓存支持 TTL 和容量限制。
- **修复**：引用图片优先复用已有描述，支持多模态模型命中关键词看原图。

## ⚠️ 注意事项

1. **关闭系统转述**：使用本插件前，请务必将 AstrBot 系统设置中的「默认图片转述模型」留空！
2. **关闭系统等待**：若启用「自定义等待机制」，请务必在系统设置中关闭原有的「只 @ 机器人是否触发等待」！
